Daomar.dev 是一个面向 AI 原生产品的孵化入口：从真实场景出发，把 AI 编程代理、自动化工作流和轻量业务应用打磨成可被直接使用的产品。

我们关注三件事：让 AI 工具服务真实工作流，让产品保持简单可解释，让数据和执行路径尽量留在用户可控环境中。

Daomar 的产品原则

不追求炫技，而是把 AI 能力放进稳定、可理解、低摩擦的使用体验里。

真实场景优先从开发者、多设备协作、活动抽奖等明确需求切入。
简单大气页面和产品都尽量减少噪音，让用户快速理解价值。
可持续迭代优先选择低运维、易扩展、便于移动端访问的架构。

当前项目

Daomar.dev 目前孵化两个应用：一个面向 AI 编程代理工作流，一个面向公平随机抽选场景。

AgentFleet

面向 AI coding agents 的多设备编排工具。提交同一个 prompt，让多台已加入的设备分别用本地代理执行任务，并汇总对比结果。

Open Source Developer Tool No hosted backend
  • 适合比较 Claude Code、GitHub Copilot CLI、Cursor、Aider 等代理输出。
  • 通过 OneDrive 同步任务与结果，不需要服务器、SSH mesh 或控制平面。
  • 支持命令行和 Web Dashboard。
