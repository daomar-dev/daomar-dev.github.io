What we believe

The best AI products are not the loudest. They quietly fit into a workflow, respect user data, and earn their place by being genuinely useful — week after week.

How we build

Three principles guide every product that ships under daomar.dev.

Real workflows first We start from concrete pain — developers comparing AI agents, hosts running fair draws — not from abstract demos.
Calm by default Clean surfaces, predictable behavior, minimal noise. The product should explain itself in seconds.
Built to last Low-ops architectures, portable data, mobile-friendly UIs. We optimize for years, not launch week.

Currently shipping

Two products in active development, each solving a real, narrow problem well.

AgentFleet

One prompt, every AI coding agent, every machine.

AgentFleet orchestrates AI coding agents across multiple devices. Send one prompt; let each enrolled machine run its local agent — Claude Code, Copilot CLI, Cursor, Aider — then compare the outputs side by side. No hosted backend, no SSH mesh, no control plane to babysit.

Open source Developer tool Local-first
  • Compare Claude Code, Copilot CLI, Cursor, Aider and others on the same task.
  • Sync prompts and results via OneDrive — no server, no SSH mesh.
  • Use the CLI or the web dashboard, whichever fits your flow.

Lucky Draw

Fair, fast, frictionless random draws.

Lucky Draw is a clean web app for fair random selection — giveaways, classroom picks, community gifts, conference raffles. Paste your candidates, draw a winner in one click, and trust the result.

Web app Fair random Mobile-ready
  • Paste candidates, draw winners instantly — no setup, no signup.
  • Transparent randomness, designed to feel fair to every participant.
