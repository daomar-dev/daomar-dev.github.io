Daomar

Build with principle. 刀马 · 道码

Daomar is a small developer-tools brand focused on sharp, principled systems. The name carries two readings: 刀马, the boldness of a swordsman, and 道码, code shaped by craft and technical honor.

AgentFleet

The first Daomar product. Distributed agent orchestration without a control plane, built for multi-machine coding workflows.

Open source

Development happens in public under the Daomar GitHub organization, with AgentFleet as the first production-facing repository.
